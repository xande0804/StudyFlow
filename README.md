# StudyFlow 📚

Aplicativo mobile para organização de estudos, desenvolvido com React Native (Expo) e Firebase.

## Proposta

O StudyFlow ajuda estudantes a organizar **matérias**, **tarefas** e **provas**, acompanhar prazos e manter sessões de foco com um temporizador Pomodoro.

## Funcionalidades planejadas

- Cadastro e autenticação com e-mail e senha
- Matérias com professor opcional e identificação por cores
- Tarefas e provas vinculadas a matérias
- Dashboard com compromissos de hoje, atrasados e dos próximos sete dias
- Histórico de atividades concluídas, com opção de reabrir
- Lembretes locais configuráveis de tarefas e provas
- Pomodoro personalizável, com persistência local
- Sincronização de informações acadêmicas via Firestore entre dispositivos

## Desenvolvimento

Projeto em construção conforme SPEC aprovada. O fluxo Git adotado será:

- `main`: versões estáveis
- `develop`: integração das funcionalidades
- `feature/*`: implementação de cada funcionalidade, integrada por Pull Request

O guia definitivo de instalação, configuração do Firebase e as capturas de tela serão incluídos antes da entrega.

## Tecnologias previstas

React Native, Expo, Firebase Authentication, Cloud Firestore e Git/GitHub.

## Trabalho acadêmico

Projeto final da disciplina de Programação para Dispositivos Móveis — Análise e Desenvolvimento de Sistemas.
